## 后续工作

长任务执行：默认 160 回合、可配置到 1000；额度暂停与无进展暂停使用独立原因。直接续跑保留计划版本，不重复写入；测试覆盖噪音字段、提醒先于暂停、版本往返、持续不同编辑及有界历史。进展检测没有额外模型调用，尚未对真实重构任务的误报率作规模评估。

优先验证真实模型在长任务、上下文压缩后续跑和工具错误修正时的质量；完善远程 MCP 认证、复杂文档编辑与渲染验证；验证真实网站、邮箱及 Windows 多屏操作。原始七阶段的主要模块均已接入，不以“有代码”代替所有外部场景都通过验收。
