# 本地通用 Agent：需求基线

完整原始规格保存在 ../requirements-source.txt。本项目按该规格开发；本文记录可追踪的产品边界。

- Windows 本地优先，React 网页与 Electron 共用 FastAPI、SQLite 和单任务队列。
- 外部模型由用户配置；无密钥使用显式 Scripted Provider 演示真实工具，不能冒充智能模型。
- 聊天不自动执行工具；执行任务经过需求、计划、权限与反馈。工具参数严格校验。
- 文件能力仅限规范化工作区。任意命令、生成代码、MCP、桌面和浏览器提交独立授权，cwd 不是沙箱。
- 持久化事件、任务、会话、授权、用量和记忆。中断恢复不自动重复副作用。
- 多配置模型、凭据安全存储、文档、检索/浏览器、技能、MCP、调度、桌面和可选协作按阶段推进。
- 无真实 API、账户、Unity/Office 或安装包验证时如实标记，不能以模拟协议替代实测。

验收状态见 acceptance.md；实现进度见 progress.md。
