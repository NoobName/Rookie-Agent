# 当前需求与边界

当前版本：0.7.1。原始规格见 [requirements-source.txt](../requirements-source.txt)，这里只描述当前产品要求。

- Windows 本地优先。网页、桌面共享会话、项目、模型配置、执行历史与单任务队列。
- 普通问答也可调用工具和交付文件，并遵循底部模型、权限、协作设置。项目绑定名称和工作区。
- “帮我审批”允许工作区内文件读写、创建和修改文档；路径越界、版本冲突仍检查。“都要申请”按调用确认。终端可由用户一次授予可撤销的工作区长期权限，cwd 不构成沙箱。
- 工具参数严格验证；错误以结构化工具结果进入后续模型请求。每轮累计错误达到可配置上限（默认 3）停止派发，明确告知用户原因和下一步。拒绝授权不得被模型重试绕过。
- UI 使用“正在进行”“需要用户操作”“上一条输出已结束”等状态，不给成果自动下“任务失败”的结论。底层错误、退出码和中断证据保留；计划检查独立记录，由用户接受结果。
- 所有动作先记录再执行，恢复时不自动重放可能有副作用的操作。新反馈、计划更新、继续执行均可追溯。
- 上下文按模型配置进行预算及自动压缩；完整证据保留本地。估算与供应商真实用量分开显示，压缩不等于无损记忆。
- 真实 API 密钥存操作系统凭据库，不以明文配置导出。无密钥时可运行明确标注的脚本模型；不能将脚本行为当作真实模型能力。
- 多模型协作默认关闭，开启后子模型仅提供建议，不能自行越过授权写文件。外部浏览器提交、邮件、MCP 和桌面操作仍走统一授权。
- 当前文档只保存最新状态。验证区分实际本地工具、协议替身、用户实测与尚待验证的外部服务。
